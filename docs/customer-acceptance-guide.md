# 客户验收测试指南

1. 打开交付方提供的 `/admin` 地址；当前版本未设置登录功能，可直接进入管理后台。
2. 点击“上传视频”，选择一个测试视频，并等待进度显示 100%。
3. 在视频列表确认标题、`fileId`、状态“可播放”和上传后约 3 天的过期时间均正确。
4. 点击“播放”，确认播放页成功打开且视频画面和声音正常。
5. 返回后台点击该视频的“生成短链”，确认页面提示短链已生成并复制。
6. 在新的浏览器窗口粘贴短链，确认它跳转到同一视频并可正常播放。
7. 记录列表中的过期时间；到期后再次打开播放链接和短链，应看到“视频已过期/无法播放”，且后台状态变为“已过期”或“已删除”。

> 验收环境若不等待 3 天，由交付人员使用专门的可删除测试视频执行加速过期测试，客户只需观察失效结果。
